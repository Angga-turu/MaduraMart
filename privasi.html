MaduraMart

Kebijakan Privasi

Terakhir diperbarui: 15 Oktober 2026

MaduraMart adalah aplikasi kasir yang dibuat oleh Kelompok 4 sebagai proyek tugas kuliah. Halaman ini menjelaskan data apa yang diproses aplikasi dan bagaimana data itu diperlakukan.

Data yang diproses

  • Akun: nama lengkap, alamat email, kata sandi (dikelola oleh Firebase Authentication dan disimpan dalam bentuk hash, bukan tulisan asli), dan foto profil jika kamu mengunggahnya.
  • Data usaha yang kamu masukkan: produk, harga, stok, transaksi penjualan, dan pengaturan toko.

Tempat penyimpanan

Semua data di atas disimpan di Google Firebase (Firebase Authentication untuk akun dan Cloud Firestore untuk data usaha) milik proyek MaduraMart. Data tiap akun dipisah: aturan keamanan hanya mengizinkan pemilik akun membaca dan mengubah datanya sendiri, sehingga pengguna lain tidak bisa melihatnya. Karena tersimpan online, data bisa dibuka dari perangkat mana pun setelah masuk. Perlu diketahui, pengembang sebagai pemilik proyek Firebase secara teknis dapat melihat data di konsol Firebase, tetapi tidak membagikan atau menjualnya.

Layanan pihak ketiga

  • Google Firebase: akun dan data usaha diproses di server Google sesuai kebijakan privasi Google.
  • Google Fonts: huruf aplikasi dimuat dari server Google, sehingga Google dapat menerima alamat IP perangkatmu sesuai kebijakan privasinya sendiri.
  • jsDelivr: pustaka untuk membuat file Excel di halaman Laporan dimuat dari jaringan jsDelivr.
  • Aplikasi ini tidak memakai iklan, alat analitik, maupun cookie pelacak milik pengembang.

Berbagi data

Data tidak dijual dan tidak dibagikan kepada pihak lain oleh pengembang.

Mengelola dan menghapus data

  • Hapus riwayat transaksi atau seluruh data lewat menu Pengaturan → Data. Untuk menghapus akun sepenuhnya, hubungi Kelompok 4 lewat WhatsApp (kontak di bawah).
  • Unduh cadangan lewat menu Pengaturan → Data sebelum menghapus data.
