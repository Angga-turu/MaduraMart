MaduraMart

Kebijakan Privasi

Terakhir diperbarui: 10 Oktober 2026

MaduraMart adalah aplikasi kasir yang dibuat sebagai proyek tugas kuliah. Halaman ini menjelaskan data apa yang diproses aplikasi dan bagaimana data itu diperlakukan.

Data yang diproses

  • Akun biasa: nama lengkap atau nama tampilan, nama pengguna, kata sandi (disimpan hanya dalam bentuk acak/hash, bukan tulisan asli), dan foto profil jika kamu mengunggahnya.
  • Masuk dengan Google: nama, alamat email, foto profil, dan ID akun Google yang diberikan Google kepada aplikasi. Aplikasi hanya meminta informasi dasar ini, tidak mengakses Gmail, Drive, kontak, atau data Google lainnya.
  • Data usaha yang kamu masukkan: produk, harga, stok, transaksi penjualan, dan pengaturan toko.

Tempat penyimpanan

Semua data di atas disimpan di browser perangkatmu sendiri (penyimpanan IndexedDB). Data tidak dikirim ke server milik pengembang, karena aplikasi ini tidak memiliki server. Akibatnya, data satu perangkat tidak bisa dilihat dari perangkat lain atau oleh pengguna lain, dan data dapat hilang jika kamu membersihkan data browser.

Layanan pihak ketiga

  • Google: tombol “Masuk dengan Google” dan huruf (Google Fonts) dimuat dari server Google. Google dapat menerima alamat IP dan menyimpan cookie sesuai kebijakan privasinya sendiri.
  • jsDelivr: pustaka untuk membuat file Excel di halaman Laporan dimuat dari jaringan jsDelivr.
  • Aplikasi ini tidak memakai iklan, alat analitik, maupun cookie pelacak milik pengembang.

Berbagi data

Data tidak dijual dan tidak dibagikan kepada pihak lain oleh pengembang.

Mengelola dan menghapus data

  • Hapus riwayat transaksi atau seluruh data lewat menu Pengaturan → Data, atau hapus data situs ini lewat pengaturan browser.
  • Unduh cadangan lewat menu Pengaturan → Data sebelum menghapus data.
  • Untuk mencabut izin login Google, buka myaccount.google.com/permissions lalu hapus akses MaduraMart.
